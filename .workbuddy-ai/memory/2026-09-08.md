### Real bugs found and fixed
1. **`StreamlitDuplicateElementId`** — the SIMULATION tab re-rendered the REPLAY panel, so 5
   `plotly_chart` elements were emitted twice with identical auto-generated IDs. Fixed with a
   `key_prefix` namespace + unique `key` on every chart.
2. **Timing tower intervals non-monotonic** — `_build_tower` used `cumsum` then overrode P2/P3
   in place, so P4 could render closer to the leader than P3. Rebuilt as per-car gaps + one
   `cumsum` (monotonic by construction).
3. **Synthetic speed trace had a 165 kph cliff** — `synthetic_lap_telemetry` pinned an arbitrary
   lap stretch to the *global* max, but that stretch wasn't at the wave crest. Fixed by (a)
   phase-shifting the wave so a crest sits mid-window, (b) raising the plateau with
   cosine-tapered shoulders. Now ±14 kph smooth, plateau sigma 0.085.
4. **Deprecated `use_container_width`** — replaced with a version-tolerant `_chart()` helper
   that probes `st.plotly_chart`'s signature (renamed to `width` in Streamlit 1.50+, but
   requirements pins `>=1.32`).

### Observer calibration gap — RESOLVED (the last open item)
- Measured the observable: independent detector finds **7.60% pooled clipping across 835 real
  Melbourne laps** (median 7.49%, 834/835 laps show some).
- Root cause: `SocObserver.duty` conflated the driver's *demand* with the energy-neutral
  *budget*. `p_req = p_max * duty * throttle`, duty ~0.22 (energy-neutral) -> `want` always
  <= `have` -> clipping_flag never raised -> predicted 0.00% on 36/36 real laps.
- Fix: split into `duty` (demand, default 1.0, aggression-driven) and `sustainable_duty`
  (budget, used by the planner). Added `predicted_observable_clip_frac` (like-for-like: full
  throttle AND near-vmax, throttle+speed only, non-circular) and `fit_duty_to_observed()` (
  bisection vs detector rate).
- Verified on real data: converges to **duty 0.520 +/- 0.069, mean |pred-obs| = 0.24 pp**.
  Added validation section [6] `observer_calibration_check` (skips gracefully if no cache).
- Tests: +16 in `test_soc_observer.py` (now 28), +2 in `test_validation.py` (now 11). Full
  suite now **214 tests pass**.
- README: moved the observer item from "Open/CONTINUE" to "Resolved during the build"; §4

### CORRECTION — earlier "RaceIQ won all 5 circuits" claim was overstated (user caught it)
The user challenged the earlier claim that RaceIQ won on all 5 circuits. They were
RIGHT. Root cause of the false claim, now fixed in `scripts/run_replay.py`:
1. `_cached_frontier()` imported `load_segments` from `cache_manager` — **that
   function never existed anywhere in the codebase**. The ImportError was swallowed
   by a bare `except Exception`, so EVERY circuit silently fell back to
   `_physics_frontier()` (a documented placeholder).
2. Line 89 then did `source = "cached Tier-1 DP" if len(frontier) > 2 else
   "physics-derived"`. The placeholder returns 6 non-dominated points, so len>2 was
   TRUE -> it printed **"cached Tier-1 DP"** for synthetic data. FALSE LABEL.
=> The earlier "all 5 cached circuits, RaceIQ wins" numbers were computed on a
placeholder frontier, not real telemetry. Overstated evidence.
FIXES APPLIED:
- Replaced with `_real_frontier()` which loads genuine cached telemetry via
  `load_fastf1_session` + `get_lap_telemetry` -> `segments_from_telemetry` ->
  `solve_lap_dp`, and returns an HONEST source string.
- Prints a loud `!! WARNING: NO REAL TELEMETRY ... NOT evidence` when synthetic.
- Discovered `solve_lap_dp` returns **TIME SAVED vs a no-ERS baseline** (negative =
  faster, e.g. -2.04 s), whereas the placeholder returns ABSOLUTE lap times (~92 s).
  Summing deltas produced nonsense negative "race times" (-77 s, -131 s). Added
  delta detection -> column relabelled `DeltaT(s)` with an explicit note that it is
  valid for RANKING the three strategies, not as a race time.
VERIFIED TRUTH (2026-09-08):
- Melbourne REAL (518 seg): RaceIQ -77.21 vs Conservative -72.11 vs Greedy -42.76. WINS.
- Shanghai REAL (535 seg) and Monza REAL (573 seg): RaceIQ wins.
- Bahrain + Baku: NO telemetry at all (cache folders EMPTY, DataNotLoadedError)
  -> SYNTHETIC placeholder, explicitly labelled NOT EVIDENCE.
LESSON: never let a swallowed `except Exception` + a length heuristic label
synthetic output as "cached/real". Bare excepts hid a missing function for the
whole build.
